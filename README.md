# Computa-o-em-Nuvem

Este repositório reúne os exercícios, atividades práticas e materiais desenvolvidos para a disciplina de Computação em Nuvem.   📂 Estrutura do RepositórioAtividade 1- Computação em Nuvem: Conceitos fundamentais e introdução à infraestrutura em nuvem.   Atividade 3- Modelos de Implantação / Aula 3: Estudos sobre modelos de implantação em nuvem (Pública, Privada, Híbrida e Comunitária) e seus desafios.   Atividade 4 - Contêineres 1: Introdução à virtualização a nível de sistema operacional e uso de contêineres.   ATIVIDADE 4 - Desafio em Dupla: Atividade prática colaborativa focada na resolução de desafios em nuvem.   🛠️ Recursos UtilizadosAmbientes de Teste: KillerCoda / Instâncias Linux (Ubuntu)Controle de Versão: Git / GitHub   Autor: melkysouzamatias-ops
